# Контент-план Telegram-канала @tvoitrenerrf

**Цель:** привлечь аудиторию на **ТвойТренер.рф** — заявки клиентам и заявки инструкторам.  
**Гео-фокус:** Сочи · Красная Поляна · Сириус · Сочинский край (+ Россия).  
**Тон:** живой, полезный, без «рекламного крика»; юмор дозированно.  
**Формат поста (обязательно):** фото (Provod / с сайта) + официальный логотип-водяной знак + HTML-текст + кнопка **«Подобрать тренера → ТвойТренер.рф»** + внизу `🔥 ❤️ 🥱 ⛺ 💥` и призыв к комментариям.

UTM для всех CTA с канала:
```
?utm_source=tg&utm_medium=post&utm_campaign={рубрика}_{дата|id}
```

---

## 1. Аудитории (кого зовём)

| Сегмент | Боль | Что обещаем в посте | Куда ведём |
|---------|------|---------------------|------------|
| Клиент «хочу занятие сегодня» | Не знает, к кому идти | «На линии сейчас» + вид спорта | `/?specialization=…` или профиль |
| Клиент «готовлюсь к событию» | Афиша без подготовки | Событие + «подготовься с тренером» | `signup_url` / карта |
| Новичок | Страх / «с чего начать» | 1 совет + CTA к инструктору | `/sport/{slug}` |
| Инструктор | Нет клиентов | «Приходи к нам» / кейс | `/landings/prichodi` или `/instructor/apply` |
| Фанат локального спорта | Хочет новости края | Афиша Сириус / Поляна | сайт + обсуждение |

## 2. Сетка дня (3 слота МСК)

Совпадает с cron `telegram_news_bot`: **08:00 / 14:00 / 18:00**.

| Слот | Рубрика | Задача | CTA |
|------|---------|--------|-----|
| **08:00** | Афиша / гео-новость | Зацепить «что сегодня в спорте региона» | «Подобрать тренера» → сайт |
| **14:00** | Живая связка / подготовка | Связать событие или спорт с инструктором | Профиль / фильтр по спорту / online |
| **18:00** | Польза / вовлечение | Совет, юмор, опрос, UGC-разбор | Карта / apply / комментарий |

**Плюс вне расписания (авто с сайта):**
- `instructor-approved` — новый инструктор
- `instructor-online` — «на линии»
- `event-published` — событие с сайта

Не дублировать один и тот же спорт/событие в соседних слотах одного дня.

## 5. Шаблоны постов (структура текста)

### A — Афиша
1. Эмодзи + **жирный заголовок**: событие — дата — место  
2. 1–2 предложения атмосферы (без выдуманных фактов)  
3. Эмодзи вида спорта  
4. ⚠️ **Важно:** практический совет  
5. CTA на ТвойТренер.рф + кнопка  
6. `🔥 ❤️ 🥱 ⛺ 💥` + «💬 Комментарии открыты…»

### B — На линии
1. 🟢 / спорт-эмодзи + **Имя · спорт · город**  
2. «Можно записаться сейчас»  
3. Совет про скорость ответа  
4. Кнопка на `profile_url`

### C — Новый инструктор
1. Эмодзи + **Имя — спорт — город**  
2. Коротко: проверен на сайте, можно смотреть отзывы  
3. Кнопка на профиль (фото инструктора, не AI-лицо)

### D — Польза
1. Вопрос или миф в заголовке  
2. 1 конкретный совет  
3. «Разберёте с инструктором на ТвойТренер.рф»  
4. Deep-link на `/sport/…` или `/`

### E — Опрос
1. Вопрос без спойлера  
2. Варианты в тексте (или Telegram Poll отдельным сообщением)  
3. После сбора — пост-результат + CTA к online-инструкторам этого спорта (`GET /api/bot/instructors?sport=&online=1`)

### F — Юмор
1. Ситуация без токсичности и без шуток «ниже пояса»  
2. Мягкий вывод → тренер / сайт  
3. Не чаще 1–2 раз в неделю в прайм

### G — Найм
1. «Инструкторам: свои клиенты с карты»  
2. Без обещаний «гарантированного заработка»  
3. CTA → `/landings/prichodi` или `/instructor/apply`

## 6. Правила вовлечения

- В каждом посте: **1 CTA**, не три ссылки.  
- Реакции канала зафиксированы: 🔥 ❤️ 🥱 ⛺ 💥 — напоминать внизу поста.  
- Комменты — только если у канала включена **группа обсуждения** (настройка TG).  
- Не публиковать выдуманные цены/даты; афиша — из парсеров или с сайта.  
- Логотип на фото: **только** `logo-tvoytrener-official.png`.  
- Не обещать автоподписку в TG после регистрации на сайте.
