## Почему письма Вебмастера могли идти на viva-r

Уведомления идут не «на кабинет», а на **email из настроек Вебмастера / Яндекс ID**.  
Если в ID привязан адрес viva-r — отчёты уходят туда.

Исправление (1 минута):  
https://webmaster.yandex.ru/notifications/ → **Настроить** →  
**Адрес для почтовых уведомлений** → `tvoitrenerrf@yandex.ru` (или основной ящик `TvoiTrenerrf`) → **Изменить адрес**.

## Не смешивать

- Не логиниться в Директ/Метрику/Вебмастер под `viva-r` для ТвойТренер.
- На сайте только `NEXT_PUBLIC_YANDEX_METRIKA_ID=111110026`.
