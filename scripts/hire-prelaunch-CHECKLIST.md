## Сделайте вручную (бесплатно, 15–20 мин)

### A. Метрика — создать цели (API не пускает)

https://metrika.yandex.ru → счётчик **111110026** (логин `TvoiTrenerrf`) → Цели → JavaScript-событие:

| Идентификатор | Название |
|---|---|
| `instructor_apply_submit` | Анкета инструктора (отправка) |
| `instructor_apply_success` | Анкета инструктора (успех) |
| `landing_instructor_cta` | Клик CTA лендинга инструктора |
| `register_submit` | Регистрация клиента |
| `order_paid` | Оплата заказа |

### B. Авито

1. Вставить текст из `avito-instructor-vacancy-READY.md`  
2. Сохранить шаблон автоответа  
3. На новые отклики — только шаблон со ссылкой  

### C. Яндекс Бизнес

Вставить описание из `yandex-business-card-BRIEF.md` (категории, TG, фото).

### D. Директ (после модерации, **перед** большим бюджетом)

1. Пополнить баланс (минимум, чтобы снять «не оплачена»)  
2. Запустить **MICRO \| Инструкторы \| Приходи** (`713299932`) утром  
3. Клиентскую MICRO можно чуть позже  

Пока баланс 0 — кампании в OFF, это нормально.
