# Отчёт: микро-воронки Яндекс Директ (04.08.2026)

## Цель
Две раздельные воронки с минимальной ценой клика:
1. **Клиенты** → регистрация / заявка инструктору  
2. **Инструкторы** → лендинг «Приходи» / анкета

## Экономика «максимум показов за минимум денег»

| Параметр | Значение | Почему так |
|---|---|---|
| Дневной бюджет | **300 ₽** | Минимум Директа (ниже API не принимает) |
| Ставка ключа | **1 ₽** | Микроставка → дешёвые аукционы / нижние позиции |
| Стратегия | **HIGHEST_POSITION** (ручная) | Совместима с дневным бюджетом; платим только за клик |
| РСЯ | OFF | Не сжигаем бюджет на дешёвый мусорный трафик сети |
| Минус-слова | Жёсткие раздельные списки | Клиентская ≠ наймовая воронка |

> «Бесплатно крутить» Директ в полном смысле нельзя: показ в поиске почти всегда платный.  
> Что сделано максимально близко: минимум ставки + минимум дневного бюджета + только поиск + точные ключи + 2 креатива в группах (ротация лучших).

## Воронки

```
Клиент:  запрос → объявление → /gorod/... или /register → регистрация / заявка
Инструктор: вакансия/работа → /landings/prichodi или /instructor/apply → анкета
```

Скрипты:
- `scripts/yandex-direct-setup-micro-funnels.ps1`
- `scripts/yandex-direct-micro-funnels-data.json`

## Что сделать вам вручную (критично)

1. **Пополнить баланс Директа** (иначе кампании не активируются).  
2. Дождаться **модерации** объявлений → затем в UI: «Запустить».  
3. В Метрике **вручную** создать цели (API токеном Директа цели создать нельзя — 403):
   - `register_submit`
   - `instructor_apply_submit`
   - `order_paid`
4. Через 3–5 дней смотреть: CTR, отказы, цели, поисковые запросы → чистить минус-словами.

## Ожидание по цифрам (ориентир)

При 300 ₽/день и ставке ~1–3 ₽: десятки кликов/день максимум, не сотни.  
Фокус — **дешёвый целевой клик**, не «закрыть весь Сочи».

## Чего Директ не делает сам

- Не даёт бесконечные бесплатные показы  
- Не регистрирует людей без сильного оффера на посадке  
- Цели Метрики нужно завести в интерфейсе Метрики
