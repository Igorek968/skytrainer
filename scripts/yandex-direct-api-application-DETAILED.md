## Описание взаимодействия приложения «ТвойТренер» с API Яндекс Директа

### 1. Назначение
Приложение автоматизации рекламы сайта **ТвойТренер.рф** (маркетплейс персональных тренировок) использует **API Яндекс Директа JSON v5** для разового/редкого создания поисковой кампании по набору инструкторов. Посадочная страница объявлений: `https://твойтренер.рф/landings/prichodi`.

Авторизация: OAuth 2.0, заголовок `Authorization: Bearer <token>`.  
Язык реализации: PowerShell + HTTPS-запросы к `https://api.direct.yandex.com/json/v5/`.  
Логин Директа: `viva-r`. Application ID: `da94d6cd18084ef8bf0fddd52883e569`.

### 2. Используемые сервисы и методы

| Сервис | Метод | Назначение |
|--------|--------|------------|
| `campaigns` | `get` | Проверка доступа и чтение списка кампаний перед созданием |
| `campaigns` | `add` | Создание 1 текстово-графической поисковой кампании (РСЯ выключена) |
| `adgroups` | `add` | Создание групп объявлений (до 6 групп по категориям) |
| `ads` | `add` | Создание 1 текстового объявления в каждой группе |
| `keywords` | `add` | Добавление ключевых фраз в группу (пакетно, одной группой за вызов) |
| `campaigns` | `suspend` | Пауза кампании после создания (без автозапуска расходов) |

Другие методы (статистика, изменение ставок в цикле, массовое редактирование) **не используются**.

### 3. Последовательность вызовов (один прогон скрипта)

1. `campaigns.get` — убедиться, что API доступен; получить текущие кампании.  
2. `campaigns.add` — создать одну кампанию (Name, StartDate, DailyBudget, NegativeKeywords, TextCampaign: Search=HIGHEST_POSITION, Network=SERVING_OFF).  
3. Для каждой из N групп (N ≤ 6), **последовательно**:  
   3.1. `adgroups.add` (1 группа, RegionIds = Сочи);  
   3.2. `ads.add` (1 объявление TextAd: Title, Title2, Text, Href с UTM, DisplayUrlPath);  
   3.3. `keywords.add` (все ключи этой группы одним запросом, обычно 6–10 фраз).  
4. `campaigns.suspend` — приостановить созданную кампанию.

Итого за один полный прогон: **примерно 2 + 3×N + 1** запросов (при N=6 ≈ **21** запрос). Параллельные запросы **не выполняются** (очередь из 1 потока).

### 4. Частота вызовов

- Скрипт запускается **вручную** оператором (не cron, не фоновый демон).  
- Типичная частота: **1–3 раза в месяц** при запуске/обновлении набора инструкторов; не непрерывно.  
- Между запросами внутри прогона — пауза **≥ 400 мс**.  
- Одновременных запросов от приложения: **не более 1** (лимит Директа — до 5; мы сознательно ниже).  
- Повторный запуск не создаёт кампании «в цикле каждую минуту»; при ошибке прогон останавливается.

### 5. Обработка ошибок

1. Разбор JSON-ответа; при наличии объекта `error` — логирование `error_code`, `error_string`, `error_detail`.  
2. Код **152** (недостаточно баллов / Units) и **506** (превышен лимит одновременных запросов): экспоненциальный backoff (5–120 сек), до **5** повторов того же вызова.  
3. Ошибки валидации объектов в `result.AddResults[].Errors`: прогон прерывается, частичный объект не считается успешным без `Id`.  
4. Сетевые/невалидный JSON: повтор с backoff; после исчерпания попыток — аварийный выход.  
5. Кампания после успешного создания сразу переводится в `suspend`, чтобы исключить непреднамеренный расход до ручного включения.

### 6. Учёт ограничений API Директа

1. **Баллы (Units):** читается HTTP-заголовок `Units` (потрачено / осталось / суточный лимит). При остатке &lt; 50 баллов — дополнительная пауза 60 сек. При ошибке 152 — ожидание и повтор.  
2. **Параллелизм:** строго 1 активный запрос (не превышаем лимит 5 одновременных).  
3. **Лимиты объектов в одном вызове:**  
   - `campaigns.add` — 1 кампания за вызов (лимит метода до 10);  
   - `adgroups.add` / `ads.add` — по 1 объекту за вызов;  
   - `keywords.add` — один пакет ключей одной группы (обычно &lt; 20; в пределах лимита метода).  
4. **Песочница:** поддерживается режим Sandbox (`api-sandbox.direct.yandex.com`) для отладки без влияния на боевые кампании.  
5. **Безопасность:** токен хранится вне кода (`.env`); приложение не передаёт доступ третьим лицам; не выполняет финансовые операции списания — только создание структуры объявлений и пауза.

### 7. Кратко для модератора
Приложение — внутренний инструмент рекламодателя ТвойТренер для **редкого** создания поисковых кампаний через API v5 методами `campaigns.get/add/suspend`, `adgroups.add`, `ads.add`, `keywords.add`, с последовательными вызовами, паузами, учётом Units и повторными попытками при 152/506. Автоматического круглосуточного опроса API нет.
