# QA Handoff

Этот документ можно отправлять тестировщикам вместе со ссылкой на стенд.

## 1) Ссылка и доступ

- Base URL: `https://<ваш-домен>`
- Admin login: `https://<ваш-домен>/admin/login`
- Роли:
  - Admin: `SKIINSTRUCT_ADMIN_EMAIL` / `SKIINSTRUCT_ADMIN_PASSWORD`
  - Клиенты и инструкторы: создаются сидами, пароль `Password123!`

## 2) Что проверять в первую очередь

- Регистрация и вход по credentials.
- Поиск инструкторов на `/client`:
  - фильтры по пользователю/активности;
  - карта и список.
- Поток заказа:
  - создание заказа клиентом;
  - принятие/отклонение инструктором;
  - статусы в кабинетах.
- Чат заказа:
  - отправка/получение сообщений в обе стороны.
- Админка:
  - вкладки `/admin/activity`, `/admin/metrics`, `/admin/orders`, `/admin/moderation`;
  - поиск в сайдбаре и сохранение фильтров между вкладками.

## 3) Быстрый smoke-check (для владельца стенда)

- `GET /api/health` -> `200`
- Главная `/` -> `200`
- `/admin/login` открывается
- `/client` после логина загружается без 500
- Создание заказа проходит до статуса ожидания инструктора

## 4) Ограничения текущего QA-стенда

- Stripe/Google могут быть отключены, если ключи не заданы.
- Push-уведомления зависят от VAPID-ключей.
- Первые запросы после деплоя могут быть медленнее из-за прогрева кешей.

## 5) Формат баг-репорта

- URL страницы
- Роль и логин пользователя
- Шаги воспроизведения
- Ожидаемое поведение
- Фактическое поведение
- Скриншот/видео
- Время (с таймзоной)
