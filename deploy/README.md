# Данные Caddy на VPS

Каталоги `caddy-data/` и `caddy-config/` монтируются в контейнер Caddy вместо анонимных Docker-томов.

- После первого выпуска сертификата на сервере: `.\scripts\caddy-sync-certs.ps1 -Pull`
- Перед деплоем (если сертификат уже есть локально): сертификаты уезжают на VPS вместе с `deploy-vps.ps1`

**Не коммитьте** содержимое `caddy-data/` (приватные ключи Let's Encrypt).
