# Твой Тренер — логотипы для рекламы и партнёров

Готовые файлы для баннеров, презентаций, печати и соцсетей.

Эталон: `../logo-tvoytrener-official.png` / `.svg` — **Твой Тренер** (с пробелом).

## Файлы

| Файл | Назначение |
|------|------------|
| `logo-mark-transparent.png` | Знак без фона (веб, наложения) |
| `logo-mark-on-white.png` | Знак на белом (документы, печать) |
| `logo-horizontal-transparent.png` | Знак + **Твой Тренер** без фона |
| `logo-horizontal-on-white.png` | Знак + название на белом |

## Правила

- В логотипе: **Твой Тренер** (два слова, с пробелом).
- В текстах сайта/канала можно писать **ТвойТренер.рф**.
- **Твой** — бирюза `#027676`.
- **Тренер** — тёмно-синий `#2E3E55`.
- Не искажайте пропорции, не меняйте цвета фигур.
- На тёмном фоне используйте варианты с прозрачным фоном.

## Цвета бренда

- Бирюза (левая фигура / «Твой»): `#027676`
- Тёмно-синий (правая фигура / «Тренер»): `#2E3E55`
